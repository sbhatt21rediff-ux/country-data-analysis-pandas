#  Country Data Analysis using Pandas

This repository contains a comprehensive data analysis project performed on a global demographics dataset using **Python** and **Pandas**. The analysis is structured to answer various critical questions about world population, regional layouts, and political insights.

##  Dataset Overview
The dataset contains structured information about countries worldwide, including:
- **Demographics:** Country Names, Capital Cities, Populations (Urban/Rural).
- **Geography:** Regional and Continental classifications, Latitude, Longitude.
- **Metrics:** Democratic frameworks and political administration.

---

##  Questions Addressed in this Project

###  Population & Capitals
1. Which country has the highest population?
2. What is the capital of the country with the highest population?
3. Which country has the least population?
4. What is the capital of the country with the least population?

###  Regional Insights
5. Top 5 countries with the highest democratic score.
6. How many total unique regions are there?
7. How many countries lie in the Eastern Europe region?
8. Which country in the African region has the highest population?

###  Political Systems
9. How many countries have "Republic" in their full name?
10. How many countries are there whose political leaders are unknown?
11. Who is the political leader of the 2nd highest populated country?

---

##  Tech Stack & Concepts Used
- **Language:** Python 3
- **Libraries:** Pandas, NumPy
- **Environment:** Google Colab / Jupyter Notebook
- **Core Operations:** Boolean Indexing, String Operations (`.str.contains`), Aggregations (`.sum`, `.idxmax`, `.idxmin`), and Data Filtering.
